# ATT&CK data

`enterprise-attack.json` is the official MITRE ATT&CK Enterprise v19.2 STIX bundle.
The application loads it once during startup and does not require Internet access afterward.
The data remains subject to MITRE's terms in `LICENSE.txt`; it is not relicensed
under the ATT&CK Visualizer project license.

To replace the version, download the matching Enterprise bundle from the official
`mitre-attack/attack-stix-data` repository, keep this filename, update the configured
version, and restart the application.
